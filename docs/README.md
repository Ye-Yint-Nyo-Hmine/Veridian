# Veridian documentation

- `getting-started/` — install, first run, writing your first stack.
- `architecture/` — how the kernel, plugin runtime, and bricks fit together.
- `bricks/` — reference for each shipped brick and its contract.
- `plugin-development/` — how to build and publish a brick, in Python or TypeScript.
- `security/` — the capability model and its Milestone 1 limits.
- `specifications/` — `protocol.md`, the normative wire-format spec. Schemas live in `/schemas`.
